# Standard library coverage

Generated by `./gradlew :compiler:stdlibCoverage` from the Kotlin stdlib and the JDK on k2l's classpath; don't edit by hand.

Each public function, property and constructor is called by a generated probe (a small Kotlin function) that k2l transpiles in-process. A name is *supported* when every probe of every overload translates, *partial* when some do, and *unsupported* when none does. Probes call operators and infix functions in their syntax, pass lambdas as trailing lambdas, and try each function with only its required arguments and with all of them. Names marked (utf16) translate only with `--strings utf16`. *Untested* names are deprecated, experimental (opt-in), or could not be probed (the reason is listed). Supporting a name here means k2l translates the call; the test cases in `compiler/src/test/cases` check what it does against the JVM.
